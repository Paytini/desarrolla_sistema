# Plugin puente de WordPress

Fuente del plugin `Desarrolla360 Bridge`, que conecta este portal con WordPress + Tutor LMS Pro por REST API — el portal nunca lee la base de datos de WordPress directamente.

El plugin vive en [`desarrolla360-bridge/`](desarrolla360-bridge/README.md). Se edita en este repo pero **se despliega manualmente**: no hay CI que lo suba a WordPress, hay que volver a subir el `.zip` del plugin cada vez que cambia.
