# Assets estáticos

Servidos por Next.js desde la raíz (`/archivo.svg`, `/assets/...`).

| Carpeta / archivo | Contenido |
| --- | --- |
| `assets/` | Logos del portal, `portal-diagram.svg` y `assets/signatures/instructors/` — firmas PNG de instructores usadas al generar constancias DC-3 (ver [`docs/dc3-metadata.md`](../docs/dc3-metadata.md)) |
| `illustrations/` | Ilustraciones SVG usadas en la UI (constancias, estudio, chat) |
| `templates/dc3.pdf` | Plantilla oficial DC-3 que rellena `src/lib/dc3/pdf.ts` |
| `file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg` | Iconos por defecto del starter de Next.js, sin uso funcional en el portal |
